Optional hardware add-on

CC Meter LCD Setup

Install the dedicated CC Meter interface on the JCZN or Guition ESP32-4848S040 4-inch 480x480 display.

Firmware 1.0.2 | Windows host | USB connection

Important: this replaces the display's current firmware. The installer first reads and saves a complete 16 MB factory backup, and it stops without flashing if that backup is incomplete.

Before you start

  • Use only the square 480x480 board marked ESP32-4848S040. Do not use this image on a 480x800 model or another ESP32 display.
  • Install the matching CC Meter desktop release first.
  • Connect the display directly to the Windows computer with its CH340 USB cable.
  • Install Espressif esptool if it is not already available: py -m pip install esptool.

You can validate the package, esptool installation, checksum, and detected COM port without changing the display:

powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-CCMeter-LCD.ps1 -ValidateOnly

Install the LCD firmware

  1. Extract every file from this ZIP into one writable folder.
  2. Open PowerShell in that folder.
  3. Run the command below. The script detects a single connected CH340 COM port, validates the firmware checksum, saves the factory image, writes CC Meter, and verifies the flash.
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-CCMeter-LCD.ps1 -IUnderstandThisReplacesFirmware

If automatic detection selects the wrong CH340 device, specify the display port explicitly, for example:

powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-CCMeter-LCD.ps1 -Port COM3 -IUnderstandThisReplacesFirmware

Connect it to CC Meter

  1. Open CC Meter Settings and enable Hardware display.
  2. Keep the transport set to USB. CC Meter detects the display automatically and updates it every 30 seconds.
  3. Optionally enable display-only mode to hide the desktop bar while keeping the tray process and LCD updates active.

Keep the backup

The installer leaves a file named CCMeter-factory-backup-YYYYMMDD-HHMMSS.bin beside the setup files. Copy it somewhere safe. It is the exact pre-install contents of your display's flash.

Do not publish or substitute another board's backup. Factory images can differ between sellers and hardware revisions.
