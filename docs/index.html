Burn Pace

Not a cost tracker. One question mid-session.

Dollar totals do not tell you when a 5-hour or 7-day subscription window is about to slam shut. CC Meter computes pace = % used ÷ % elapsed for every window so you know instantly if you are coasting or heading into a wall.

0.4x

Coasting

You are burning quota well below the clock rate and will finish the window with generous headroom.

1.0x

Right on the clock

At your current rate, you will hit 100% right as the window resets. Steady pace, zero waste.

1.6x

Hitting the wall early

You are burning 60% faster than time is passing — time to shift heavier work to another pool before throttling.

Three Providers

One local gauge for every subscription you burn.

Every provider is auto-detected from your machine. Tools you do not use stay hidden automatically — override any meter in Settings or the tray menu.

Claude Code 5h · Weekly · Model

Tracks your 5-hour session window, weekly all-models pool, and per-model weekly caps (Opus, Fable, or whichever your plan scopes).

Source: Direct OAuth call using local ~/.claude/.credentials.json + shared usage-cache.json.
Safety: Automatic token renewal, strict 15-min cadence, shared persisted 429 backoff.
Codex Account-Wide Live

Reports the exact account-wide windows your Codex subscription currently exposes without inventing missing windows from stale logs.

Source: Local codex app-server RPC (account/rateLimits/read), 5-min cache.
Safety: CC Meter never touches your OpenAI tokens; Codex CLI handles its own auth.
Gemini 5h · Weekly

Reads live Gemini 4 model quota pools directly from your Antigravity account, converting remaining quota to percent used with pace and countdowns.

Source: Official agy -p "/usage" --output-format json, 5-min cache (optional cache file fallback).
Safety: Spends 0 tokens, creates 0 conversations, never reads Google credentials.
Windows Desktop Widget

A 29 px top-edge strip or a full countdown panel.

Lives in the system tray, never clutters the taskbar, and never steals focus when you toggle it.

Compact strip mode — docks cleanly against the top screen edge Optional auto-hide · Hover top edge to slide in · Drag edges to resize

Auto-hiding screen-edge wedge

Flip the AUTO switch to slide the strip up to a 3 px peek along the top edge. Touch the edge with your cursor and it glides right back down.

Tray tooltip & display-only mode

Hover the tray icon for an instant summary across all active providers. If you use the ESP32 desk screen, hide the desktop widget completely while the tray keeps feeding USB.

Per-user Start with Windows

Off by default. Writes one per-user HKCU\...\Run key — no admin privileges, no background service, and stays in sync with Task Manager's Startup tab.

Zero surprise updates

Updates are checked only when you click Check for updates... in the tray menu. Nothing phones home on startup, on focus, or on a timer.

ESP32-4848S040 Hardware Display

Put your rate limits on a ~$25 4-inch touch screen.

Dedicated open-source firmware for the widely available JCZN / Guition ESP32-4848S040 (480×480 RGB IPS + GT911 capacitive touch). Plug in one USB-C cable and leave your browser tabs closed.

Physical Guition ESP32-4848S040 running CC Meter over USB-C Test unit cost CHF 21.39 shipped

One USB cable does everything

Power, live JSON updates over the onboard CH340 UART, touch-triggered refreshes, and PC focus-timer audio all share one cable. No Wi-Fi setup needed (optional token-protected LAN mode is built in).

Flicker-free PSRAM double buffering

Full 480×480 off-screen canvas with cache-aligned partial row flushes on minute updates and targeted arc-end patches on the focus ring — zero scan-out flicker or sideways jump.

Swipe left for a Pomodoro Focus Timer

25/5 focus blocks with NVS persistence, 6 tap-to-cycle ring colors, PC WebAudio cues, and optional HTTPS webhook logging to focus-webhook.json for every finished block.

01

Install CC Meter

Run the matching Windows installer. It carries the USB bridge and never touches your board on its own.

02

Grab Firmware ZIP

Download and extract CCMeter-LCD-Firmware-1.1.5.zip from GitHub Releases.

03

Connect via USB

Plug the square ESP32-4848S040 directly into your PC. CH340 COM port is detected automatically.

04

Backup & Flash

Follow the included offline SETUP.html. The script saves a verified 16 MB factory backup before flashing.

05

Enable Display

Open Settings → Hardware display → USB in CC Meter. Live meters appear within seconds.

Architecture & Transparency

No cloud backend. No telemetry. Read every line.

Everything stays on your machine. Provider credentials never leave the standard CLI tools or Anthropic's OAuth endpoint, and never touch the ESP32.

Unsigned installer & build from source

The Windows installer is unsigned, so SmartScreen will show "Windows protected your PC" (click More info → Run anyway). Prefer not to trust a binary? Build it yourself in three commands (Node 20+):

git clone https://github.com/silverdolphin863/claude-code-meter.git
cd claude-code-meter
npm install && npm test && npm run dist

Honest scope & related projects

CC Meter is Windows-only for now and focuses on a low-cost square Guition panel driven over one USB cable alongside a desktop tray gauge. Great related projects worth checking out:

  • TokenMonitor — polished 4-inch 480×480 Wi-Fi desk display for Claude, Codex & Antigravity.
  • Clawdmeter — cross-platform (Win/macOS/Linux) Bluetooth ESP32 Claude Code meter.
  • TokenMeter — Windows USB bridge + 2.8-inch ESP32 touch display.
  • codeMeter — pre-built standalone Wi-Fi hardware display.
